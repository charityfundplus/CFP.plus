Hồ Sơ Thương Vụ • Deal ID

Khi một cơ hội đủ điều kiện chuyển thành thương vụ, TMTC tạo Deal ID độc lập. Deal ID không thay thế ID của Buyer, Seller, Enterprise, Product, Service hoặc Country.

Deal ID • Buyer ID • Seller ID • Product hoặc Service ID • Country Origin ID • Country Destination ID • Quantity • Standard • Incoterms • Price Reference • Payment Terms • Logistics • Evidence • Verification Status.

Ngành Nghề Và Doanh Nghiệp

Khi bản đồ ngành nghề được chuẩn hóa, doanh nghiệp không cần một hệ ngành riêng. Mỗi doanh nghiệp giữ một Enterprise ID tại Chương 7 và liên kết tới Industry ID, Product ID, Service ID, Country ID và Evidence phù hợp.

Enterprise ID + Industry ID + Country ID + Product hoặc Service ID + Evidence.

Quốc Gia • Prefix • Ngôn Ngữ

Country ID vẫn là khóa dữ liệu quốc gia. Tiền tố quốc gia chỉ là lớp Website Context dễ nhận biết cho Con Người và phải resolve về đúng Country ID trong Registry.

Country Prefix ≠ Language. Một Website theo quốc gia có thể hỗ trợ nhiều ngôn ngữ mà không thay đổi Country ID hoặc Entity ID.
