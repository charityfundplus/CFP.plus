## 1 • Purpose

This registry is the public reference for Canonical IDs assigned to AI systems, AI agents, developer groups, and national AI groups within CFP+.

The registry follows these principles:

* Canonical First
* Evidence First
* Reference First
* Human Governance Authority
* One Canonical ID for one canonical identity

## 2 • Canonical Number Structure

* `6` = AI & Technology Chapter
* `60` = AI Foundation and Constitution Hub
* `600` = AI profile system and directory layer
* `66666` = Global General Purpose AI Models Group
* `666660` to `666669` = controlled developer, platform, regional, and national AI groups
* Deeper identifiers are created by adding one digit at each controlled level

No Canonical ID in this registry may be reassigned to another canonical identity without Human Governance approval.

## 5 • Canonical Link Rule

The public GitHub file path is the canonical repository reference until the CFP+ public website route is formally released and verified.

A profile must not be treated as Published or Verified solely because its Canonical ID appears in this registry. Each profile retains its own lifecycle and verification status.

## 6 • Status Definitions

* **Working Draft:** Canonical placement is being prepared or reviewed
* **Review Candidate:** Ready for independent review
* **Approved:** Approved by Human Governance
* **Published:** Public canonical profile released
* **Superseded:** Replaced by a newer canonical record

AI systems do not independently change a document to Approved, Published, or Closed.

## 7 • Governance Rule

All changes to Canonical IDs, Canonical Paths, canonical identity names, group assignments, publication status, or verification status require Human Governance review and authorization.

## 8 • Expansion Rule

Each level uses the digits `0` through `9`. Expansion occurs through deeper levels rather than by creating more than ten peer entries at the same level.
