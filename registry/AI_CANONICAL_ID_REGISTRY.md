## 0 • Canonical Structure

- `69` = Global AI Country Hub.
- Every national AI hub is placed under `69`.
- The national AI hub ID is formed by concatenating `69` with the country's numeric calling code without the plus sign.
- Formula: `AI Country Hub ID = 69 + Country Calling Code`.
- Existing canonical examples:
  - `691` = United States AI Hub for calling code `+1`.
  - `6981` = Japan AI Hub for calling code `+81`.
  - `6982` = South Korea AI Hub for calling code `+82`.
  - `6984` = Vietnam AI Hub for calling code `+84`.
  - `6986` = China AI Hub for calling code `+86`.
  - `6991` = India AI Hub for calling code `+91`.
- Deeper IDs identify developers, AI systems, models and integration nodes under the applicable country hub.
- Shared calling codes, territories and exceptional cases require a documented Human Governance allocation decision before Canonical Lock.

## 3 • Canonical Rules

- One Canonical ID = One Entity
- One Canonical ID = One Direct Link
- All national AI hubs belong under Root Hub `69`
- Country-derived hub IDs preserve the published country relationship
- IDs must not be reassigned after Canonical Lock
- Human Governance controls material changes and exception handling
