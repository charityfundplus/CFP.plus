# HUB 69 • SHORT LINK ID STANDARD • V2

## Quy tắc bắt buộc
Mọi ký tự chữ phải nằm trước tên miền `cfp.plus` dưới dạng subdomain.
Sau dấu `/` chỉ được phép là Canonical ID bằng số.

- GitHub: `https://gh.cfp.plus/<ID>`

- Notion: `https://nt.cfp.plus/<ID>`

## Guardrail
Không dùng dạng `cfp.plus/gh/<ID>`, `cfp.plus/gg/<ID>`, `cfp.plus/nt/<ID>` hoặc bất kỳ ký tự nào sau tên miền. Sau `/` chỉ có số. Canonical ID không thay đổi giữa các kho. Target URL dài thật của từng nền tảng được resolver ánh xạ phía sau.
