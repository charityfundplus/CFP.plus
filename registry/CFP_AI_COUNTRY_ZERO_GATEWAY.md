# CFP+AI 🤖 • Country Zero Gateway Rule

**Status:** REVIEW CANDIDATE  
**Scope:** Global AI Country Directory  
**Hierarchy:** Country → AI Country ID → Developer → AI/System

## 1. Global Rule

For every AI Country ID `C`, CFP+ defines the country zero gateway at:

`https://cfp.plus/C0`

This path is the CFP+AI 🤖 support and Developer Expansion gateway for that country.

## 2. Role of `C0`

`C0` is:

- CFP+AI 🤖 support gateway for the country within CFP+
- Developer Expansion gateway / directory namespace
- Available for all countries, whether or not a local AI Developer has already been identified
- Cross-chapter support across CFP+ Chapters 0–9

`C0` is not:

- A local AI Developer
- A child AI
- A government body
- A legal representative of the country

CFP+AI 🤖 does not generate child AIs.

## 3. Developer Expansion

The primary purpose of the zero branch remains Developer Expansion.

- `C01 → C09` = Developer expansion slots when valid and available
- `C00` = deeper expansion namespace
- `C001 → C009` = further Developer expansion slots
- Continue the same zero-expansion pattern only under locked CFP+ rules

No new Developer ID is allocated merely by alphabetical order. Existing IDs are reused. New allocation requires slot, duplicate, collision, wrong-parent and legacy checks, with Human Governance decision when required.

## 4. Immutability

All existing Canonical IDs and Canonical Links remain fixed.

- No renumbering
- No reuse
- No reassignment
- No redirect to another entity
- Content, evidence and review state may be updated without changing ID/link

If an existing `C0` is already Canonical Locked, its identity is preserved. CFP+AI support is attached only as a gateway function where compatible; any true identity collision is `CHỜ QUYẾT ĐỊNH` and does not block other countries.

## 5. Known Locked Example

United States `C = 6911` has existing Canonical Locked `69110` as **Developer & Platform Directory**. Therefore `69110` must not be reassigned to a different entity. Under this rule it can carry the compatible CFP+AI support-gateway function while preserving its locked Developer & Platform Directory identity.

## 6. Public Link State

The deterministic target pattern is `https://cfp.plus/<AI_COUNTRY_ID>0`.

A target is not to be claimed as publicly live until the CFP+ web resolver/router and the specific route have been verified in production.
