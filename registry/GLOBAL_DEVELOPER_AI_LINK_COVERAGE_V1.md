# CFP+ Global Developer • AI Link Coverage

**Mục tiêu:** phủ toàn cầu theo cùng một công thức, không duy trì bảng mapping cũ gây xung đột.

## Công thức

`Country → AI Country ID → Developer → AI / AI con 👶 → https://cfp.plus/<ID>`

## Mỗi Developer cần

`ID • Name • Country • Parent AI Country ID • Official Source • Permanent Link • AI children • Review Status`

## Mỗi AI / AI con cần

`ID • Name • Parent Developer ID • Country • Official AI URL/Source • Primary Function • Permanent Link • Evidence • Review Status`

## Quy tắc coverage

- Phủ trước ở mức tương đối, sau đó tiếp tục bổ sung.
- Có ID/link nhưng chưa bind tên → `RESERVED / PENDING`.
- Có tên nhưng evidence chưa đủ → `REVIEW CANDIDATE`.
- Chỉ ghi `VERIFIED` hoặc `ACTIVE` khi có evidence đúng phạm vi.
- Không suy diễn từ khoảng trống số.
- Không renumber/reuse ID đã cấp.
- Không dùng `/hub/69/...`.
- Tất cả public link dùng trực tiếp `https://cfp.plus/<ID>`.

## Nguồn chuẩn

- Public routing: `registry/global-country-ai-index.json`
- Entity binding: `registry/ai-entity-registry.json`
- Country metadata: `registry/country-route-map.json`
- Chuẩn duy nhất: `registry/CFP_GLOBAL_AI_ID_LINK_MASTER_STANDARD.md`

Mọi bảng cũ khác chỉ là lịch sử/review evidence, không được dùng để tự cấp hoặc đổi ID.
