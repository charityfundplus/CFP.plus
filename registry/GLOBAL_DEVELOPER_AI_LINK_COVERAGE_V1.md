## 4 • AI child profile template

Every child AI profile should contain:

- **AI Canonical ID**
- **AI Name**
- **Parent Developer ID**
- **Country Canonical ID**
- **Parent Chapter 6 ID**
- **Official AI URL**
- **CFP+ Canonical Link**: `https://cfp.plus/<AI-ID>`
- **GitHub Registry Link**: `/registry/<AI-ID>.md`
- **Notion Work Lane / permanent link**
- **Primary function**
- **Evidence / Source**
- **Review Status**
- **Updated Date**

### Reusable child link pattern

`Developer → AI child → https://cfp.plus/<AI-ID> → GitHub /registry/<AI-ID>.md → Notion Work Lane`
