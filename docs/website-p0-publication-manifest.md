## Goal
Publish existing CFP+ materials to the Website through a single numeric-ID navigation system, not as a separate registry. Public route: `https://cfp.plus/<digits>` (no date, slug, /hub/, trailing slash, parameters). HUB 69 is the sole gateway. This document is a publication plan, not proof that links are live.

1. Site skeleton: 5 navigation groups V, 000, 135, 246, 789; 10 Chapters 0–9, each with recursive 0–9 descendants.
2. Numeric-ID index with actual pages, Parent lineage, breadcrumb navigation, clear evidence state, and valid links.

5. Individual specialized tasks, permissions, source references, and Notion profile links. Do not display sensitive internal incident data or confidential investigations.
6. Review other 10-Chapter materials and country/developer/AI profiles for verified sources and public eligibility.
