## 9 • Quy tắc sắp xếp và chuyển tài liệu

1. Canonical ID là thứ tự quản lý chính.
2. Một tài liệu Canonical chỉ có một file chính.
3. Không tạo lại nội dung đã có dưới tên khác.
4. Notion giữ vai trò Source of Truth trong giai đoạn làm việc hiện tại.
5. GitHub là nơi công bố công khai, version, review và evidence sau khi đủ điều kiện.
6. Thứ tự chuyển: Foundation → Constitution → Charters → Standards → Registry → Website → Operations → Review → Archive.
7. Mọi file phải ghi rõ Document Type, Lifecycle Status, Governance Authority và Canonical Language.
8. Mọi thay đổi phải có commit message rõ ràng và liên kết bằng chứng khi cần.
