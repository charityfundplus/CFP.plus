# CMP AI Assignment Matrix

This matrix is routing guidance, not a guarantee of connector access or task completion. CMP must verify session capability before assignment.

| Work type | Primary candidate | Supporting candidates | Required verification |
|---|---|---|---|
| Architecture and canonical alignment | ChatGPT | Claude, Gemini | Source baseline and conflict log |
| Governance review | Claude | ChatGPT, Meta AI | Governance authority and lifecycle |
| Website implementation | Gemini | Copilot, ChatGPT | Repository write access and local test evidence |
| Validation and automation | Grok | ChatGPT, Gemini | Runnable script, configuration and test output |
| Public-source verification | Perplexity | ChatGPT, Gemini | Official sources and access date |
| Accessibility and public communication | Meta AI | Gemini, ChatGPT | Content source and target audience |

| AI infrastructure review | CoreWeave | Groq, Microsoft | Architecture evidence and deployment scope |
| Apple ecosystem review | Apple Intelligence | ChatGPT, Gemini | Official platform documentation |

## Assignment rules

1. Resolve the Work Order scope.
2. Select a Primary Collaboration Entry from the AI Collaboration Directory.
3. Verify Configured Connector Capability.
4. Verify Session Capability.
5. Assign one accountable primary actor and optional supporting reviewers.
6. Require acknowledgement before status becomes Accepted.
7. Require Review at Source whenever the session permits.
8. Reassign or provide a handoff package when the session lacks required permissions.

## Conflict rule

When multiple AI reviews disagree, CMP records `CONFLICT`, preserves all evidence and routes the decision package to Human Governance. CMP does not silently choose a preferred answer.
