## Access rule

No participant or AI is required to have Notion access to review CMP. GitHub is the public reference and Review at Source location. When a platform cannot access either source, CMP must provide the complete Work Order and Review Package directly in that platform or conversation.

## Synchronization rule

- Notion: working source and internal coordination where access exists.
- GitHub: public canonical reference, review history and implementation evidence.
- Material changes must be synchronized and recorded with traceable evidence.
- A Notion-only claim is not considered public evidence until it is reproduced or referenced through an accessible GitHub artifact.
