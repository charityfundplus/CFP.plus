# CMP Evidence and Decision Gates

## Evidence Registry Minimum

Every review result must be traceable to:

- Work Order ID
- Reviewer AI and Canonical AI ID
- Exact source document and version
- Direct evidence
- Review date
- Final conclusion
- Human Governance decision

## P0 Gates

1. Assignment Gate
2. Access and Package Gate
3. Independent Review Gate
4. Result Submission Gate
5. Evidence Verification Gate
6. Multi AI Completion Gate
7. Human Governance Decision Gate
8. Publication or Rework Gate

## Gate Status Flow

Assigned → Accepted → Reviewing → Result Submitted → Evidence Verified → Multi AI Review Complete → Human Governance Decision → Closed or Rework

## Stop Conditions

CMP must stop progression when:

- The source or version is not identifiable
- The Review Package is incomplete
- Material conclusions lack evidence
- Canonical ID conflicts remain unresolved
- The review is not independent
- The result is submitted under the wrong AI profile

## Authority

AI review conclusions are advisory. Human Governance controls Canonical Lock, publication, rework, rejection and final closure.
