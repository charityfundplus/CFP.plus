# CMP • Collaborative Multi AI Protocol

**Placement:** HUB 69 → CMP  
**Lifecycle Status:** Active P0  
**Governance Authority:** CFP+ Human Governance  
**Source of Truth:** Notion  
**Public Reference:** GitHub

> HUB 69 is the single Canonical Gateway of CFP+. CMP is the central collaboration and coordination layer between humans and AI. CMP is not a second HUB.

## P0 Functions

1. AI Registry
2. Work Queue
3. Evidence
4. Review and Decision Gates

## Operating Flow

Human Governance → HUB 69 → CMP → Canonical AI Profile → Work Order → Review Result → Evidence Verification → Human Governance Decision

## Platform Access Rule

No single platform is guaranteed to be accessible to every AI.

When an AI cannot access Notion, GitHub or another external link, CMP must deliver the complete Work Order and Review Package directly in that AI conversation or as an attached file.

A review must not be stopped solely because one external platform is inaccessible.
