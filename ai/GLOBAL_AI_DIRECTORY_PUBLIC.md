## Public Rules

- One entity → one numeric ID → one primary CFP+ link after confirmation.
- Do not create parallel IDs for the same entity.
- Collisions or insufficiently supported mappings remain `NEEDS REVIEW` or `PENDING`.
- Credentials, tokens, secrets and technical access data are never published.
- `Listed ≠ Connected ≠ Authorized ≠ Active ≠ Contributing`.
