## 7. Governance Boundary
AI may learn, update, normalize, review, correct and propose improvements within permitted scope.
AI must not alter Founder Locked decisions, CFP+ DNA, Constitution, Charter, Canonical Locked IDs/Links or any decision requiring Founder approval.

If escalation is required:
`AI LEARN / UPDATE → CMP CROSS REVIEW → EVIDENCE PACKAGE → FOUNDER REVIEW REQUIRED → FOUNDER DECISION → IMPLEMENT / HOLD / REJECT`

## 8. Sync Rule
The same `AI_LANE_ID` is the cross-platform key in Notion, GitHub and Google.
Notion is the working Source of Truth for lane status and operational records.
GitHub stores technical/canonical artifacts and machine-verifiable evidence.
Google stores collaborative working documents and operational datasets where appropriate.
A platform is never treated as synchronized unless a real write/read verification exists.
